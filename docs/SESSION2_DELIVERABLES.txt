CONFIGURATION PRESETS:
  Fast Mode:       1 iter,  2 results, 200 chars  (~1-2 sec)
  Balanced Mode:   3 iter,  3 results, 500 chars  (~3-6 sec) [DEFAULT]
  Thorough Mode:   4 iter,  6 results, 900 chars  (~6-10 sec)
  Research Mode:   5 iter, 10 results, 1500 chars (~10-15 sec)

BUG FIX 1: RESPONSE CONCATENATION
- Problem: New responses replaced previous ones
- Cause: Improper slice logic (chat_history[:-1] + [new_msg])
- Solution: Check last message role, update or append
- Result: Multiple Q&A pairs accumulate correctly
- Tests: 3 dedicated test cases

BUG FIX 2: SERVER RESTART
- Problem: Server restart lost active conversation
- Cause: Always loaded first chat, not most recent
- Solution: Load chat with max timestamp
- Result: User's chat auto-loads on restart
- Tests: 3 dedicated test cases
